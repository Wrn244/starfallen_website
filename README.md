# Will Starfallen Website

This is a static character website for Will Starfallen. Open `index.html` in a browser to view it.

## What to customize

- In `index.html`, replace the About Me copy with your real bio.
- Update the History of Will Starfallen section with your official lore.
- Adjust the Abilities tabs if Will has different powers, costs, or weaknesses.
- Contact links currently point to YouTube, Suno, MidJourney, FictionLab, and `will.starfallen@gmail.com`.

## Files

- `index.html` contains the page content.
- `styles.css` controls the visual design and mobile layout.
- `script.js` powers the mobile menu, active navigation, ability tabs, contact form, and animated starfield.
- `assets/will-starfallen-full-ability-codex.docx` is the downloadable full ability codex linked from the Abilities section.
- `assets/will-starfallen-banner.png` is the homepage hero banner image.
